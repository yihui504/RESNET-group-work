# ResNet 课程设计 · 复现实施规划

> 需求来源：deep-interview 规格（6 轮访谈，最终模糊度 12.5%）。
> 目标：CIFAR-10 上复现 ResNet 演进主线，趋势正确即可，3 人初学者团队，单卡 ≥3 周。

## 1. 复现清单（1 个对照 + 4 个关键历史版本 + 1 个消融）

| # | 模型（命令行名） | 历史对应 | 验证的论点 | 预期趋势（趋势正确即算成功） | 文献参考值 |
|---|---|---|---|---|---|
| 0 | `plain20` / `plain32` | ResNet 论文图 4 对照网 | 退化问题真实存在 | plain-32 训练误差 ≥ plain-20；两者都被 ResNet 反超 | 原文：plain-20 err≈9.4%、plain-32 err≈9.8% |
| 1 | `resnet20` / `resnet32` | He et al., CVPR 2016 (v1) | 捷迹连接修复优化 | 同深度下明显优于 plain；训练曲线平坦下降 | 原文：ResNet-20 err≈8.8%、ResNet-32 err≈7.5% |
| 2 | `preact20` / `preact32` | Identity Mappings, ECCV 2016 (v2) | 块内顺序影响信号传播 | 同深度精度持平或更优，收敛更快 | 原文趋势一致即可（1001 层可训） |
| 3 | `wrn28_10` | Wide ResNet, 2016 | "加宽"正交轴 | top-1 95-96% 量级，明显优于深窄网 | 原文：err 4.00%（36.5M 参数） |
| 4 | `resnext29_16x4d` | ResNeXt, CVPR 2017 | 基数（分组卷积）优于单纯加深加宽 | 相近/更低 FLOPs 下精度 ≥ 深窄 v1（如 resnet110） | 以实测趋势为准 |
| 消融 | `seresnet20`/`seresnet32` | SENet, CVPR 2018 | 通道注意力即插即用 | SE 版比对应 v1 提升（+1% 量级趋势） | SE-ResNet 系普遍 +1pt 左右 |
| 参考 | `resnet44`/`resnet56`/`resnet110`、`wrn28_2` | （可选加训） | 用于 ResNeXt 公平对比、WRN 快速调试 | — | — |

## 2. 实验统一设置（公平性关键：所有模型同配置）

| 项 | 值 |
|---|---|
| 数据集 | CIFAR-10，标准增强：RandomCrop(32, pad=4) + RandomHorizontalFlip + Normalize |
| 优化器 | SGD，lr=0.1，momentum=0.9，weight_decay=5e-4 |
| 学习率调度 | CosineAnnealingLR（0.1 → 0），所有模型统一 |
| 训练轮数 | 200 epochs（统一；WRN 原文同为 200） |
| 批大小 | 128（显存不足时降 64 且 lr 减半为 0.05） |
| 随机种子 | 42（统一，便于复现与排错） |
| WRN 专属 | dropout=0.3（块内，原文设置） |
| 指标 | 每 epoch 记录 train/test loss 与 top-1；参数量；FLOPs（thop）；训练时长 |

> 统一 200ep+cosine 而非原文 164ep+阶梯衰减：初学者友好、曲线平滑，且不影响趋势结论。

## 3. 代码库结构（教学式：少文件、重注释）

```
resnet/
├── models/
│   ├── __init__.py      # 模型注册表：名字 → 构造函数
│   ├── plain.py         # Plain-20/32（退化对照组）
│   ├── resnet_v1.py     # ResNet-v1（BasicBlock, 2015）
│   ├── resnet_v2.py     # Pre-act ResNet（2016）
│   ├── wrn.py           # WRN-28-10（2016）
│   ├── resnext.py       # ResNeXt-29 16×4d（2017）
│   └── se_resnet.py     # SE 模块 + SE-ResNet-v1（2018 消融）
├── train.py             # 统一训练循环（一个命令训任何模型）
├── plot.py              # 汇总绘图 + 导出对比表 summary.md
├── requirements.txt
├── README.md            # 跑通指南 + 常见问题
├── results/             # 每次训练一个 JSON（含全部历史与指标）
└── figures/             # plot.py 输出图表
```

**典型命令**：
```bash
python train.py --model resnet32            # 训练 ResNet-32
python train.py --model wrn28_10            # 训练 WRN-28-10
python plot.py                              # 汇总所有已完成实验
```

## 4. 三周里程碑

| 阶段 | 内容 | 完成标志 |
|---|---|---|
| 第 1 周 | 环境安装；跑通 train.py（先用 `wrn28_2`/`resnet20` 小模型冒烟测试）；训练 plain20/32 + resnet20/32 | 退化对照图初版出来（报告核心图 1） |
| 第 2 周 | 训练 preact32、resnext29_16x4d、wrn28_10、seresnet32；（可选 resnet110 用于 ResNeXt 对比） | 全部 results/*.json 齐；中期趋势核对 |
| 第 3 周 | 异常补跑；plot.py 出全部图与 summary 表；报告撰写（对齐调研报告结构）；PPT 制作与排练 | 报告 + PPT 定稿 |

> 时间量级参考（3060 级显卡）：ResNet-20/32 级单模约几分钟/10 epoch；WRN-28-10 是最重的一项，建议放在第 2 周初开跑。

## 5. 三人分工（每人都有"可汇报的模型"）

| 成员 | 负责模型 | 兼职职能 | PPT 讲解板块 |
|---|---|---|---|
| A | plain20/32、resnet20/32 | 框架维护（train.py）、实验记录表 | 背景：退化问题 + ResNet-v1 原理与结果 |
| B | preact32、resnext29_16x4d、seresnet32 | 文献核对（数字与调研报告对齐） | v2 信号传播分析 + ResNeXt/SE 结果 |
| C | wrn28_10 | plot.py 出图、报告主线撰写、PPT 汇编 | WRN 结果 + 十年演进总结（引调研报告时间线） |

协作约定：所有实验只改 `--model` 参数不改代码；结果 JSON 统一放 `results/`；每周同步一次核对趋势。

## 6. 风险预案

| 风险 | 症状 | 处置 |
|---|---|---|
| 退化现象不明显 | plain-32 训练误差没有高于 plain-20 | ① 确认 plain 网带 BN（论文设置）；② 换 seed 重跑；③ 确认 lr=0.1 未被误改 |
| WRN 过慢/爆显存 | 200ep 跑不完或 OOM | 先 `--model wrn28_2` 验证正确性；batch 降 64 且 lr 减半；实在不行 WRN 减为 100ep 并在报告中注明 |
| ResNeXt 报错 | grouped conv 通道不匹配 | 检查 groups=cardinality 且每组通道数 = 总通道/16 为整数（代码已保证，重跑即可） |
| 趋势不符预期 | 如 v2 不如 v1、SE 无提升 | 这本身可写进报告"分析与讨论"（训练轮数、容量差异）；不要硬凑数字 |
| thop 未安装 | FLOPs 显示 N/A | `pip install thop`；或忽略 FLOPs 列，参数量不受影响 |
