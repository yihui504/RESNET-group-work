残差块解剖：一行公式如何改变一切

预计 18 分钟 · 前置：L1 · 本课教你把 y=F(x)+x 讲出三个层次

一、核心公式与它的三层含义

y = F(x, W) + x

左边是要学的目标映射，右边拆成两部分：堆叠层只负责学残差 F(x) = H(x) − x，然后原样加上输入 x。汇报时按三层递进讲：

层次一（动机层）：L1 说过，让非线性层逼近恒等映射很难。现在恒等只需 F(x)=0——把权重推向零即可，优化器极其擅长这件事。"学增量"永远比"学全部"容易。
层次二（信号层）：前向看，x 沿捷径原样直达任意深层，深网络最差也是 x 的传递；反向看，求导时 ∂y/∂x = 1 + ∂F/∂x，那个常数 1 保证梯度可以无衰减地流回任意浅层。加法是唯一同时满足"前向无损 + 反向无损"的融合方式——这就是为什么不能换成乘法或拼接后乱接。
层次三（工程层）：恒等捷径零参数、零 FLOPs、不改变输出尺寸。免费的午餐，这是它能在 2015 年一夜之间被所有实验室采用的原因。

二、BasicBlock：最简残差块长什么样

我们 CIFAR 实验用的 BasicBlock（对应 models/resnet_v1.py），结构就四步：

输入 x（16 通道, 32×32）
↓  主分支 F(x)
3×3 卷积 → BN → ReLU
↓
3×3 卷积 → BN
⇢
捷径（同形状时）
恒等 x
⊕
ReLU( F(x) + x )
捷径什么时候不能是恒等？stage 过渡处（通道 16→32、特征图 32→16）F(x) 与 x 形状不同，捷径换成一个 stride-2 的 1×1 卷积把 x 投影过来。全网络只有 3 处——这解释了 plain-110 与 resnet-110 的参数差只有 0.003M。

三、v1 → v2：把"加法"变得更干净

2016 年同团队追问：捷径必须是纯恒等吗？块内顺序重要吗？他们系统消融后发现——ReLU/BN 放在加法之后会污染直传信号。于是有了 pre-activation（v2）：

v1（post-act，2015）v2（pre-act，2016）
块内顺序conv→BN→ReLU … 加法后再 ReLUBN→ReLU 前置到卷积前，加法后无任何操作
信号通路加法结果被 ReLU 裁剪（负值归零）任意两层之间无障碍直传
收益区间通用极深网（164/1001 层）显著，浅网不明显
我们的实测resnet-32 93.82%preact-32 92.96%（−0.86pt）

这个 −0.86pt 不是坏消息，是知道适用边界的证据：v2 解决的是超深网信号传播，32 层不在收益区间。答辩被问"preact 为什么没涨"时，这句就是标准答案（详见 QA 卡 Q11）。

五、本课交付

汇报时的讲法示范（对着 PPT 块结构图说）："这个块只做一件事——让这几层卷积去学'增量'，再把输入原样加回来。要变成恒等映射，只需把增量学成零；梯度回传时有那个常数 1 兜底，一百多层也堵不住。"
