ResNet 汇报术语表

30 个术语 · 中英对照 · 答辩前过三遍 · 课程使命

一、基础概念（L1 前置，必须张口就来）

卷积层 / convolutional layer
用一个小窗口（如 3×3）在图像上滑动做加权求和，提取局部特征（边缘、纹理）。窗口权重就是网络要学的参数。
卷积神经网络 / CNN
卷积层堆叠 + 激活函数 + 池化构成的网络，靠"局部连接 + 权值共享"处理图像，是 2012–2020 视觉任务的绝对主流。
批归一化 / Batch Normalization, BN
对每个 mini-batch 的特征做标准化（减均值除方差，再学一个缩放和偏移），稳定训练、允许较大学习率。关键点：BN 已经缓解了传统梯度消失，但退化问题依然存在——这是答辩必考点。
激活函数 / activation (ReLU)
引入非线性的函数。ReLU(x)=max(0,x)：负数归零、正数保留。
随机梯度下降 / SGD
用小批数据的梯度近似更新参数：w ← w − lr·g。本项目的 momentum=0.9 表示更新方向带上历史惯性。
学习率与余弦退火 / lr, cosine annealing
步长 lr 控制每步走多远；余弦退火让 lr 从 0.1 平滑降到 0——先快跑后精修。本项目统一 200 epoch。
过拟合 / overfitting
训练误差低但测试误差高——模型背下了训练集。与退化（训练误差也降不下去）方向相反，务必分清。

二、ResNet 核心结构（L2，PPT 方法部分）

退化问题 / degradation
plain 网络加深后训练误差不降反升的现象，不是过拟合而是优化困难。本项目实测：plain-20 91.94% → plain-110 11.62%。
恒等捷径 / identity shortcut, skip connection
把输入 x 直接加到输出：y = F(x) + x。零参数、零算力、处处可微，是 ResNet 的灵魂。
残差学习 / residual learning
让堆叠层只学"增量" F(x) = H(x) − x，而不是整体映射 H(x)。网络加深时把 F 推向零即得恒等映射，深网络不再"变差"。
基本块 / BasicBlock
两个 3×3 卷积构成的最简残差块，用于 ResNet-18/34 与本项目全部 CIFAR 版网络。
瓶颈块 / Bottleneck
1×1 降维 → 3×3 → 1×1 升维的三层块，用于 ResNet-50+ 与 ResNeXt，先压缩再计算省算力。
前激活 / pre-activation (ResNet-v2)
把 BN+ReLU 从卷积后挪到卷积前，加法后不再接激活，信号可在任意层间无障碍直传。收益主要在极深网络（164/1001 层）。
下采样 / downsampling, stride-2
特征图尺寸减半（32→16→8）、通道数翻倍。捷径跨尺寸时需 1×1 卷积（stride=2）对齐形状。
全局平均池化 / global average pooling
每个通道取空间平均，8×8×64 → 64 维向量，再接全连接出 10 类得分。

三、演进轴线与变体（L3/L4，实验部分）

加宽 / Wide ResNet, WRN
通道数乘宽度因子 k（16/32/64 → 160/320/640），浅而宽胜过深而窄。WRN-28-10 = 28 层、k=10、块内 dropout 0.3。
基数 / cardinality (ResNeXt)
深度、宽度之外的第三维：并行分支数 C（分组卷积）。ResNeXt-29 16×4d = 29 层、16 组、每组 4 通道。
通道注意力 / Squeeze-and-Excitation, SE
全局池化→两层小 FC→Sigmoid，为每个通道算 0~1 的权重再乘回去，"重要通道说话大声点"。即插即用，代价极小。
分组卷积 / grouped convolution
输入输出通道分成 C 组各自卷积、互不通信，FLOPs 降为 1/C。是基数的工程实现。
结构重参数化 / re-parameterization (RepVGG)
训练时多分支（含捷径）、推理时代数融合成单路——残差"训练用完即弃"。2021 后端侧主流。

四、评估指标（报数字时的口径）

Top-1 准确率 / top-1 accuracy
预测的最大概率类恰为正确的比例。本项目 CIFAR-10 全部报 best top-1（200 epoch 中的最佳测试精度）。
参数量 / params (M)
可学习权重总数（百万）。衡量模型大小。plain-110 1.728M ≈ resnet-110 1.731M 是"同深度同容量对照"的证据。
计算量 / FLOPs (G)
前向传播浮点运算数（十亿）。衡量推理成本。注意 FLOPs 低不等于速度快（内存访问也是瓶颈）。
训练误差 vs 测试误差 / train/test error
判断"退化 or 过拟合"的判据：训练误差升=退化（优化问题）；训练降测试升=过拟合（泛化问题）。
随机种子 / random seed
控制初始化与数据顺序的随机性。本项目单种子 seed=42，<1pt 差距只说"相当"不说"更优"。

五、2025 视角关键词（L5，结论页弹药）

ConvNeXt (CVPR 2022)
把 Transformer 设计要素逐项移植回纯 CNN（大核、LN、反向瓶颈），反超 Swin——但宏观骨架仍是残差堆叠。
ViT / Swin / Vision Transformer
图像切块当 token 输入 Transformer；每个 block 仍是"注意力+残差、FFN+残差"，残差骨架被继承。
VMamba / SSM (NeurIPS 2024)
状态空间模型的视觉骨干，线性复杂度。论文原话：VSS 块"可视为带跳连的残差网络"。
DiT / Diffusion Transformer (ICCV 2023)
扩散模型主干。adaLN-Zero 把残差分支零初始化，块初始为恒等映射——ResNet 思想在生成模型中延续。
ResNet Strikes Back (2021)
仅换训练配方（Mixup/RandAugment/长程 cosine）把 ResNet-50 从 76.1% 拉到 80.4%——配方与结构同等重要。
