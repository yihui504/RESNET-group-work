# ResNet 十年演进复现：实验分析报告

> 课程设计实验部分的分析文档。所有数字均取自 `results/*_e200.json` 的实测记录（13 个模型，CIFAR-10，统一训练配置），可由 `plot.py` 重新生成。文献基准引自 `docs/ResNet发展脉络调研报告.md`。

## 1. 实验概述

本实验在同一数据集（CIFAR-10）与同一训练配置下复现 ResNet 演进主线的五个关键节点，回答三组研究问题：

- **RQ1（退化问题）**：加深无捷径的 plain 网络是否出现训练误差不降反升的退化现象？捷径连接的收益是否随深度增大？
- **RQ2（演进轴线）**：残差框架下的三条改进轴——加深（ResNet-110）、加宽（WRN-28-10）、基数（ResNeXt-29）——在精度与效率上如何权衡？
- **RQ3（即插即用改进）**：通道注意力（SE 模块）与块内顺序改造（Pre-act v2）在本实验设置下是否带来增益？

## 2. 实验设置

为保证公平比较，所有模型使用完全相同的配置（差异仅在网络结构本身）：

| 项 | 设置 |
|---|---|
| 数据集 | CIFAR-10（50k 训练 / 10k 测试，10 类） |
| 数据增强 | RandomCrop(32, padding=4) + RandomHorizontalFlip + Normalize |
| 优化器 | SGD，lr=0.1，momentum=0.9，weight_decay=5e-4 |
| 学习率调度 | CosineAnnealingLR（0.1 → 0），T_max=200 |
| 训练轮数 | 200 epochs（统一） |
| 批大小 | 128 |
| 随机种子 | 42（单种子） |
| WRN 专属 | 块内 dropout=0.3（论文原设置） |
| 硬件 | NVIDIA RTX 4060 Laptop 8GB，PyTorch 2.11 (CUDA 12.8) |
| 指标 | 测试集 Top-1 最佳值（best_acc）、参数量、FLOPs（thop）、训练时长 |

结构对照的有效性保障：Plain 网与同名 ResNet **逐层对齐**——相同入口卷积、相同三阶段通道配置（16/32/64）、相同每层卷积数，唯一差异是 ResNet 的每两层卷积组成一个残差块并引入恒等捷径。参数量验证：plain20 0.270M ≈ resnet20 0.272M；plain110 1.728M ≈ resnet110 1.731M（差异仅为 stage 过渡处捷径 1×1 卷积）。

> 复现说明：本项目曾发现 Plain 网初版实现每 stage 卷积层数少一半（深度仅为同名 ResNet 的一半），已修复并全量重跑；本报告所有 plain 系数字均为修复后结果。

## 4. 分项分析

### 4.1 RQ1：退化问题复现

**退化现象成立且单调**。无捷径的 plain 网络随深度增加，测试精度单调下降：20 层 91.94% → 32 层 90.43% → 56 层 86.39% → 110 层 11.62%。更关键的是**训练精度同步恶化**（99.26% → 98.47% → 92.32% → 10.00%），说明这是优化困难而非过拟合——更深网络连训练集都拟合不了，与 ResNet 原论文图 4 的现象一致。

Plain-110 出现完全的优化失败：训练损失 200 轮恒为 2.30（= ln 10，即十类均匀猜测），从未脱离随机平台。该表现比原论文更极端（论文 plain-110 误差 17.6%，仍能收敛到约 82% 精度），原因见第 7 节局限性讨论。但作为"退化问题的极端形态"，它反而强化了本实验的核心论点：**110 层梯度信号无法有效穿过无捷径的堆叠结构**。

**捷径收益随深度增大**（表 2）。同深度配对比较中，残差连接的精度增益从 20 层的 +1.00pt 一路扩大到 110 层的 +82.98pt；对照组 ResNet 自身则随深度单调提升（92.94% → 94.60%），形成"plain 越深越差、ResNet 越深越好"的剪刀差（图 `fig_degradation.png`）。

**表 2：同深度配对比较（唯一差异 = 捷径连接）**

| 深度 | Plain (%) | ResNet (%) | 捷径增益 (pt) |
|---|---|---|---|
| 20 层 | 91.94 | 92.94 | +1.00 |
| 32 层 | 90.43 | 93.82 | +3.39 |
| 56 层 | 86.39 | 94.14 | +7.75 |
| 110 层 | 11.62 | 94.60 | +82.98 |

### 4.2 RQ2a：加宽 vs 加深

WRN-28-10 以 96.18% 居全榜第一，比最好的深窄网络 ResNet-110（94.60%）高 1.58pt，与 WRN 论文报告的 96.0%（错误率 4.00%）几乎精确对齐（本实验错误率 3.82%）。但其代价是参数量 21 倍（36.48M vs 1.73M）、FLOPs 约 20 倍（5.25G vs 0.26G）、训练时长 4.4 倍。这印证了 WRN 论文"加宽训练更有效"的论点，同时揭示了其代价面：在本实验的低参数预算区间（<2M），加深（ResNet-110）与基数（ResNeXt-29）是更经济的选择。

### 4.3 RQ2b：基数轴（分组卷积）

ResNeXt-29 16×4d 取得 94.45%，与 FLOPs 相近（0.281G vs 0.257G）且参数更少（1.35M vs 1.73M）的 ResNet-110（94.60%）基本打平（-0.15pt）。这与原论文"同算力下 ResNeXt-50 优于 ResNet-50 约 1pt"的结论存在差距，可能原因：本实验的 29 层 bottleneck 相对较浅（仅 3 个 bottleneck/stage），基数优势在更深结构中更明显；且 200 epoch 单种子设置下 0.15pt 的差异处于噪声区间。诚实的结论是：**在本设置下，基数轴与加深轴效率相当，未观察到显著优势**。

### 4.4 RQ3a：SE 通道注意力——增益随深度显现

SE 模块呈清晰的**深度依赖性**：32 层上无增益（93.61% vs 93.82%，-0.21pt），110 层上为正（95.01% vs 94.60%，+0.41pt）。方向与 SE 论文一致（论文在 ResNet-110 上增益约 +1.2pt，在浅网/小网上增益更小），但幅度小于论文。解释：通道注意力的前提是存在足够多的通道供重标定，浅网每 stage 仅 16/32/64 通道，SE 瓶颈层（C/16）容量过小；110 层网络容量更大，SE 才有发挥空间。附带观察：SE-ResNet-110 以 1.74M 参数超过 ResNeXt-29（94.45%）与 ResNet-110（94.60%），说明在深窄结构上"加注意力"比"换结构"更便宜。

### 4.5 RQ3b：Pre-act v2 的负结果

Pre-act ResNet-32（92.96%）未能超过 ResNet-32（93.82%），差 -0.86pt。这与文献预期一致而非实验失败：v2 论文的核心收益在极深网络（164/1001 层）的信号传播与正则化，32 层浅网本就不在其收益区间。本实验补跑了 preact110 计划但因时间预算放弃（详见巡查日志）；因此本报告对该结论的表述限制为"**在 32 层深度未观察到 pre-act 增益**"，不做更深的推广。

## 6. 讨论：为什么捷径有效——三大解释与本数据的一致性

1. **隐式集成视角**（Veit et al., 2016）：ResNet 等价于大量浅层路径的集成，梯度主要由短路径贡献。本实验中 plain-110 完全无法训练而 resnet-110 训练精度达 99.98%，正是"有效路径长度"差异的极端体现：无捷径时所有梯度必须流过全部 110 层，信号衰减至无法学习。
2. **梯度破碎视角**（Balduzzi et al., 2017）：plain 网络梯度相关性随深度指数衰减（白噪声化），跳连使其降为亚线性。本实验捷径增益随深度单调放大（+1.0 → +83.0pt）与该理论的预测方向一致。
3. **损失面视角**（Li et al., 2018）：跳连显著平滑损失景观。plain 系训练精度随深度下降（99.26% → 10.00%）可解释为损失面随深度急剧恶化的可观测结果。

## 7. 局限性与效度威胁

1. **单种子**：所有实验仅跑 seed=42。配对差距 <1pt 的比较（ResNeXt vs ResNet-110 的 -0.15pt、SE-32 的 -0.21pt）在多种子下方差未估计，本报告对这类比较只作"相当/未见显著差异"表述。
2. **训练配方与原文不同**：统一 200ep + cosine 调度（为公平与初学者可复现），原论文为 164ep/64k iter + 阶梯衰减。这解释了 ResNet-110 高于论文约 3pt（更长训练），也可能解释 plain-110 的崩溃——原论文设置下 plain-110 尚能收敛到 82%，本设置（初始 lr 0.1 无预热直接打在 110 层 plain 网上）使其彻底失败。崩溃本身仍是退化问题的真实表现（优化困难），但与论文的量级不可直接比较，报告中已分开表述。
3. **preact110 缺失**：v2 深网优势未验证，相应结论限定在 32 层。
4. **训练时长非受控测量**：后台运行、断点续训、GPU 共享使时长列仅供参考。

## 8. 结论

在统一设置下的 13 组实验完整复现了 ResNet 演进主线的关键结论：(1) 退化问题真实存在且随深度单调加剧，捷径连接的收益随深度从 +1pt 放大到"能否训练"的质变，构成残差学习必要性的直接证据；(2) 三条演进轴中，加宽（WRN-28-10，96.18%）上限最高但代价约 20 倍，加深（ResNet-110，94.60%）与基数（ResNeXt-29，94.45%）在低预算区间效率相当；(3) 即插即用改进呈深度依赖——SE 注意力在 110 层 +0.41pt、32 层无增益，pre-act 在浅网无增益，均与文献方向一致。这些结果连同第 6 节的理论对照，支撑课程报告的核心叙事：**残差连接是使"深度"成为可扩展维度的先决条件，其思想被此后所有架构（ConvNeXt、VMamba、DiT）继承为默认骨架**。
